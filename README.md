# ActiveMQ MCP

Inspects Apache ActiveMQ. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/activemq-mcp

Installs from the Camillia hub as `activemq-mcp-81ca12`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
